How the system is organised

Data layer

One PassengerData model keyed by month, backed by SQLite with migrations and an admin panel for direct inspection.

Analytics

Pandas groupby produces yearly, monthly, seasonal, growth and heatmap datasets that are serialized to JSON for the charts.

Forecasting

Scikit-learn and Statsmodels fit linear, moving-average and seasonal models, scored on a held-out 20% test split.

Presentation

Django templates render Chart.js visualizations on a glassmorphism design system with light and dark themes.

Design principles

Data first

Every number is computed from the dataset, never hard-coded.

Accessible

Semantic markup, focus states and reduced-motion support.

Responsive

Mobile-first layouts from 360px up to wide desktops.

Lightweight

CSS and 2D canvas only — no heavy 3D or animation libraries.
