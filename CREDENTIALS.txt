How to Reset Password (if forgot)
-----------------------------------
python manage.py changepassword admin
  -> Enter new password twice

Or via shell:
python manage.py shell -c "from django.contrib.auth.models import User; u=User.objects.get(username='admin'); u.set_password('NewPass123'); u.save(); print('reset done')"
